# SQLAlchemy Project

## Описание

Этот проект представляет собой простое веб-приложение, в котором я игрался со сложными SQL-запросами, пробовал разные подходы: как синхронные, так и асинхронные. 

## Установка

### Предварительные требования

- Python 3.7 или выше
- pip

### Клонирование репозитория

Сначала клонируйте репозиторий на свой локальный компьютер:

```bash
git clone https://github.com/PoroSenok-sys/SQLAlchemy_project.git
cd SQLAlchemy_project
```
Установка зависимостей
Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```
Использование
Создайте и настройте базу данных. Вы можете использовать SQLite или любую другую базу данных, поддерживаемую SQLAlchemy. Настройки базы данных находятся в файле config.py.

Запустите приложение:

```bash
python app.py
```
Перейдите в браузер по адресу http://127.0.0.1:5000, чтобы увидеть приложение в действии.
Функции
- Создание, чтение, обновление и удаление записей в базе данных.
- Поддержка различных форматов данных.
- Возможность работы с различными базами данных через SQLAlchemy.
